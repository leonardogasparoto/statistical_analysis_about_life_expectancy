# Statistical Analysis of Life Expectancy

This project explores the main factors associated with **life expectancy across countries** using statistical analysis and Python.

The analysis is based on data from the **World Health Organization (WHO)** and investigates how health, socioeconomic, educational, and lifestyle indicators are related to life expectancy.

The project follows a complete data analysis workflow:

* Data exploration and understanding
* Data cleaning and missing value treatment
* Outlier analysis using the IQR method
* Feature engineering
* Exploratory Data Analysis (EDA)
* Correlation analysis
* Multicollinearity assessment
* Multiple Linear Regression using OLS
* Feature standardization
* Statistical significance analysis
* Model interpretation

The final regression model explains approximately **77% of the variation in life expectancy** within the analyzed dataset.

The analysis identified relevant statistical associations involving factors such as **adult mortality, HIV prevalence, education, vaccination coverage, nutritional indicators, and lifestyle characteristics**.

The main goal of this project is not only to build a statistical model, but also to demonstrate how data can be transformed into meaningful insights through a structured analytical process.

> **Note:** The relationships identified in this analysis represent statistical associations and should not be interpreted as causal relationships.
